# Self-Service Role Change — Implementation Plan

> **For agentic workers:** Executed INLINE by the same session (executing-plans), TDD per task. Steps use `- [ ]`.
> Full audit & root cause: [../../../ROLE_CHANGE_AUDIT.md](../../../ROLE_CHANGE_AUDIT.md). Manager decision: **full fix, one deploy**.

**Goal:** Make the "Change Your Role" flow work correctly on production — fix the frontend 404 AND bring the existing `PUT /api/v1/users/me/role` endpoint into compliance with the locked business rules.

**Architecture:** Modify the *existing* live endpoint (do NOT create `POST /change-role`). Add one column + one audit table. Keep old profile rows. Enforce 30-day cooldown + active-match block. Reissue tokens with the new role claim. Fix the frontend's `/api/v1` double-prefix and swap the token before redirect. Publish restrictions in EN/SI/TA.

**Tech stack:** FastAPI + SQLAlchemy async + Alembic; Next.js 14 App Router + next-intl; PostgreSQL; pytest (async).

## Corrected facts (verified in Phase 0 — override the task spec where they differ)

- **Endpoint already exists & is live:** `PUT /api/v1/users/me/role`, body `{new_role}`, guard `require_complete_profile`, in `govihub-api/app/users/router.py:59`. Keep this path.
- **Root-cause of "Not Found":** `ChangeRoleModal.tsx:36` double-prefixes `/api/v1` (prod `NEXT_PUBLIC_API_URL` already ends in `/api/v1`). App convention = `lib/api.ts` `api.put("/users/me/role")`.
- **Real match status enum = `{proposed, accepted, completed, dismissed}`** (migration 007). Active-to-block = `('proposed','accepted')`. `confirmed`/`disputed` from the task DO NOT EXIST.
- **Real listing deactivation** (reuse existing logic): harvest `NOT IN ('cancelled','fulfilled')`→`cancelled`; demand `NOT IN ('cancelled','closed')`→`cancelled`; supply `='active'`→`discontinued`.
- **Tokens:** `GoogleAuthService.create_tokens(db, user) -> (TokenResponse, raw_refresh_token)`; `create_access_token` embeds `role` claim; `revoke_all_user_tokens(db, user_id)`. (`app/auth/service.py`)
- **Profiles** unique per `user_id`; keep old, create target only if missing. `UserRole` = farmer|buyer|supplier|admin.
- **Beta token storage:** `sessionStorage["govihub_token"]` + cookie `govihub_token` (`beta-login/page.tsx:164-168`). No persisted refresh token for beta.
- **Migrations:** `govihub-api/migrations/versions`; head via `alembic heads`. **Prod containers:** `govihub-spices-govihub-api-spices-1`, `govihub-spices-postgres-spices-1`; DB `govihub_spices`; compose `docker-compose.spices.yml`; host VPS `govihub-mumbai`. `curl` is blocked locally — probe via VPS `python3 urllib` or sandbox.
